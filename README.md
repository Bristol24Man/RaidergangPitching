# WSU After Action Report – Streamlit app
Deploy: push this folder to GitHub, then on share.streamlit.io choose the repo and set the main file to `app.py`.
Run locally: `pip install -r requirements.txt && streamlit run app.py`
Input: tracked-session/game CSVs (columns incl. Pitcher, TaggedPitchType, PitchCall, KorBB, Balls, Strikes, Inning, PAofInning, PitchofPA). Files with "BP" in the name are skipped.
